## 1. Logo System

### Primary Logo
- Full logo: RH icon (teal/navy) + "RiteHire" wordmark in dark navy
- Icon only: "RH" monogram (for avatars, favicons, small placements)

### Logo Variants
| Variant | Usage |
|---------|-------|
| Primary (color) | Light surfaces, white backgrounds |
| Dark/Charcoal | Light surfaces, alternative |
| White | Dark surfaces ONLY (navy, teal backgrounds) |
| DO NOT use on busy photos, colored backgrounds, or distorted |

### Minimum Sizes
| Size | Use case |
|------|----------|
| 8px icon | Absolute minimum (favicons only) |
| 24px icon | App icons, small UI |
| 48px icon | Standard digital use |
| Full logo | Always maintain wordmark legibility |

### Clear Space Rules
- Minimum clear space: **1x** the logo height on ALL sides
- Do not violate the clear space boundary
- Never crop, rotate, stretch, recolor, or add effects to the logo

| Combination | Ratio | Level |
|-------------|-------|-------|
| #1a2332 on #e5e7eb | 13.9:1 | AAA |

- LinkedIn post backgrounds: prefer #1a2332 (dark) or #ffffff (light) with teal accent

## 3. Typography

### Primary Font — Headings
| Size | Weight | Example use |
|------|--------|-------------|
| 24px | Bold | Main headline, primary hook |
| 18px | Bold | Section heading, card title |
| 16px | SemiBold | Subheading, callout |

**Font style:** Clean, geometric sans-serif. Modern and readable.

### Secondary Font — Body Text
| Size | Weight | Example use |
|------|--------|-------------|
| 14px | Regular | Body copy, bullet points |
| 12px | Regular | Footnotes, captions, legal |

### Typography Rules
- Headlines: Bold, uppercase or title case — never all lowercase
- Body: Regular weight, generous line height (1.5–1.6)
- No decorative or script fonts
- No italic for headings
- Keep text hierarchy clear: one H1, max two levels below it per layout

## 4. Background Rules

### Light Surfaces
- Use: Primary (color) logo or Charcoal logo
- Background: #ffffff or #e5e7eb

### Dark Surfaces
- Use: White logo ONLY
- Background: #1a2332 (preferred) or #4a5568

### Forbidden Backgrounds
- Busy photos behind logo
- Colored backgrounds that clash with teal or navy
- Gradient backgrounds unless explicitly defined

## 5. LinkedIn Visual Specs

### Single Image Post
- Size: **1200 × 1200px**
- Safe margins: **80px** all sides
- Background: #1a2332 (dark) or #ffffff (light)
- Teal (#009886) as accent/highlight — never fill

- Size: **1080 × 1350px** each slide
- 5–8 slides max
- Same margin and color rules as above

### Visual Style Rules
- Clean, minimal, data-focused (SaaS-adjacent aesthetic)
- UI mocks: use flat, branded card style — #1a2332 bg, #009886 accent, white text
- No stock photo faces, no real client names
- Checklist cards: dark background, teal checkmarks, white bullets
- SLA/spreadsheet mocks: minimal table style, 3–5 rows only
- "Inbox" mocks: dark card, truncated subject lines, brand avatar

## 7. Apple-Design Standard (RiteHire Addition)

All RiteHire design output — regardless of tool or medium — must meet Apple-grade design standards:

### Core Principles
- **Clarity:** Every element has a purpose. Remove anything that doesn't serve the user.
- **Deference:** Content leads. Design supports, never competes.
- **Depth:** Use subtle layering (shadows, elevation) to convey hierarchy, not decoration.

### Rules
- Whitespace is a design element — use it generously
- One primary visual action per screen/card/slide
- Typography leads layout — never sacrifice readability for style
- Rounded corners: minimum 8px radius on cards and buttons
- Shadows: soft, directional (0 4px 24px rgba(0,0,0,0.12)) — never harsh
- Icons: filled, consistent weight, matched to typography scale
- Motion: purposeful micro-animations only — nothing gratuitous
- Grid: 8px base grid. Everything snaps to it.

### Quality Gate (run before shipping anything)
1. Would this look at home in an Apple product showcase?
2. Can a new user understand the hierarchy in under 3 seconds?
3. Is every pixel intentional?
4. Does it use only brand-approved colors and fonts?
5. Is the logo placed correctly with clear space maintained?

If any answer is NO — revise before shipping.

## 8. Voice in Visuals

When text appears on branded visuals:
- Lead with a specific number or operational fact
- No empty adjectives ("seamless", "world-class", "best-in-class")
- Use operational language: "SLA-defined", "approval-gated", "evidence trail"
- Every visual should make the ICP think: "this is for me"
