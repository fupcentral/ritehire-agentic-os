## 2) Hard rules (break these and the post is trash)

### Rule A — Pick exactly ONE ICP
Every post must speak to one buyer type. No "global companies + recruiters + EORs" in the same post.

### Rule B — Map to exactly ONE pillar
Every post must map to one pillar. If it's two, you didn't decide what the post is.

### Rule C — Hook validation is mandatory
Every post must pass BOTH:

**Number test:** includes 1 specific number  
Examples: %, $, days, headcount, volume, time, cadence, SLA hours

**Visual test:** includes 1 concrete scene  
Examples: inbox screenshot, SLA spreadsheet, payroll run checklist, contract clause, onboarding tracker, escalation log

### Rule D — No vague claims
Avoid:
- "best-in-class", "world-class", "seamless", "end-to-end" (unless you immediately define it operationally)
- compliance/legal guarantees you can't prove

Replace with operational proof language:
- "SLA-defined"
- "approval-gated"
- "evidence trail"
- "audit-friendly ledger"
- "statutory checklist + verification"

### Rule E — One CTA only
End with exactly one CTA. Rotate style:
- Question CTA
- Offer CTA
- Proof CTA
- Challenge CTA
