## 🔧 Engineering — RH6 Dashboard Overhaul

Today's major engineering work: **8-screen audit and full schema alignment.**

All pages were crashing or showing blank data because the dashboard was coded against an outdated `schema.sql` instead of the actual Supabase constraint values.

**Fixes shipped (committed to `github.com/fupcentral/ritehire-agentic-os`):**

| File | Fix |
|---|---|
| `types.ts` | Complete rewrite — all enums now match actual DB constraints |
| `ExecutiveDashboard.tsx` | Stage labels, priority filters, agent name map ordering |
| `Pipeline.tsx` | Stages updated to actual DB values, default form state fixed |
| `Contacts.tsx` | Status options corrected (was showing wrong filter values) |
| `ActivityLog.tsx` | Status filters fixed, agent UUID crash resolved |
| `Agents.tsx` | `skill.skill_id` → `skill.id` crash fix |
| `Finance.tsx` | `action_type` crash fixed |
| `LinkedInEngine.tsx` | Status filters + action_type crash |
| `EmailOutreach.tsx` | Status counters + action_type crash |

**Root cause:** `activity_log` table has no `action_type` column (only `skill_used`), causing `.replace()` to throw on every page. Fixed with: `(entry.skill_used ?? entry.action_type ?? 'action').replace(/_/g, ' ')` across all affected pages.
